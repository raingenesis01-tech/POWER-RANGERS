Which rooms can be used right now?

A scheduled class is not the same thing as a person in the room. If a sensor is offline or its reading is old, the room stays unknown instead of looking empty.

D1 and D2 use an all-day sample class so every status can be seen outside school hours. Rooms marked Simulated are demonstration data, not live hardware.
